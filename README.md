# Escalate17.github.io

Personal developer portfolio for **Tarang Patel**.

A single-page portfolio built with vanilla HTML, CSS, and JavaScript — no frameworks, no build step. Designed with a premium dark theme featuring glassmorphism, floating orbs, grain textures, and smooth scroll animations.

## Tech

- HTML5 + Semantic elements
- Vanilla CSS (custom design system)
- Vanilla JS (Intersection Observer, parallax, cursor effects)
- Google Fonts (Inter, JetBrains Mono)

## Deploy

This repo deploys automatically to [escalate17.github.io](https://escalate17.github.io) via GitHub Pages.

## Local Preview

```bash
# Any simple HTTP server works
npx serve .
# or
python3 -m http.server 8000
```
